# Documentation index

## Start here

- `ARCHITECTURE.md`: package layers and data flow.
- `API_STABILITY.md`: public API and output-schema guarantees.
- `GPU_BACKEND.md`: optional CUDA setup, supported operations, and diagnostics.
- `../schema/`: versioned machine-readable API and output contracts; 1.0 is
  retained as the historical baseline and 1.1 is the current schema.
- `../provenance/METHODS.md`: statistical references and software ancestry by
  algorithm.
